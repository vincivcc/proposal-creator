# 提问页规格

**所有要用户拍板的事，都放进一份 HTML，不要用对话框问答。**

理由：用户经常攒着一批问题一起处理，对话框一问一答的往返成本很高。
而且光把问题列出来还不够——用户看完还得回对话框打字，等于没省。
所以提问页必须**能勾选、能填、能传图、能一键导出**。

对话框里只留一句：「本批 N 个问题在 `<文件名>.html` 底部。」

---

## 一 · 什么时候出提问页

每个节点结束、需要用户拍板时才出。一次一批，不要边做边问。

| 节点 | 产出 |
|---|---|
| 启动 | 亮全流程节点图（文字即可） |
| 拿不准需求时 | 需求澄清页 |
| ③ 核对之后 | 数据与预算核对清单 |
| ④ 之前 | 风格与素材页 |

---

## 二 · 结构

```html
<section class="q" data-q="Q1">
  <h3>Q1 · 背景走哪个方向？</h3>
  <p class="hint">每组配缩略图，不要只给文字描述。</p>
  <label class="opt"><input type="radio" name="q1" value="A">
    <img src="data:image/jpeg;base64,...">
    <b>A · 深底冷调</b><span>接近参考方案的做法，安全</span></label>
  <label class="opt"><input type="radio" name="q1" value="B"> ... </label>
</section>
```

要点：

- **每个选项配可视化预览**。选风格这件事，文字描述没有意义，必须看图。
  预览图用 base64 内嵌，不要外链——文档要能离线打开、能单独发出去。
- **选项要带取舍说明**，不只是名字。「A · 深底冷调 —— 接近参考方案，安全」
  比「A」有用得多。
- **单选 / 多选 / 填空都要有**。填空只给真正需要用户输入的（品牌名、日期、联系人）。
- 文档**单文件、离线可开**，样式内联，不依赖任何外部资源。

---

## 三 · 逐页素材表（每份方案都要有）

每页一行，让用户一次性把所有图的事交代完：

| 列 | 内容 |
|---|---|
| 页码 | `P07` |
| 标题 | 这页的标题 |
| 这页要什么图 | 具体到「产品瓶身正面特写」这种程度 |
| 需求等级 | 必需 / 可选 / 不用 |
| 上传槽 | 拖拽区，右侧即时缩略图 |
| 批注 | 用户自由填写 |

**图非必须。** 没有的页留一个虚线占位框，并在文档里说明「留空也行，
出 PPT 时这一页会走姓名卡 / 纯文字版式」。

---

## 四 · 上传的两种走法

图片**只落在本机，不上传任何外部服务**。这一点要在文档里写明。

### 主路：File System Access API

Chrome / Edge 在 `file://` 下可用（已验证）。用户选一次 `产出/素材/` 目录，
之后每次拖图直接写进去，文件名就是素材槽名。

```js
dirHandle = await window.showDirectoryPicker({ mode:'readwrite', id:'<项目>-assets' });
// 写：const fh = await dirHandle.getFileHandle(name, {create:true});
//     const w = await fh.createWritable(); await w.write(file); await w.close();
```

要点：

- `id` 参数让浏览器记住上次选的目录，同项目复用。
- `showDirectoryPicker` 不存在（Safari / Firefox）或用户拒绝权限时，
  不要静默失败——**弹提示并说明会自动降级**：
  ```js
  if (!window.showDirectoryPicker) { toast('这个浏览器不支持写文件夹——改用「保存」下载'); return; }
  ```
- 用户取消选择会抛 `AbortError`，这个要**单独判断并忽略**，不能当成失败。

### 降级路：导出 JSON

不支持时，把图片转 base64 打包成一个 `素材包.json` 下载。
之后由 `scripts/unpack.py` 解开：

```bash
python3 "$SKILL/scripts/unpack.py" <产出目录>
```

它会把图写进 `产出/素材/`，并把风格选择和批注存成 `_素材清单.json`。
找不到时会提示找过哪两个位置（`产出/素材/` 和 `~/Downloads/`）。

### 两个必须加的保护

```js
// 图只在内存里，刷新就没了——拦一下
window.addEventListener('beforeunload', e => {
  if (Object.keys(picked).length) { e.preventDefault(); e.returnValue = ''; }
});
```

以及**导出后不要清空已选**，用户可能想改一个再导一次。

---

## 五 · 收尾

用户填完、导出之后：

1. 跑 `unpack.py`（如果走了下载那条路）
2. 确认 `产出/素材/` 里的文件名对得上素材槽
3. 重跑 deck 脚本——有图的用真图，没图的自动回退到姓名卡，不用改代码

**文件名就是接口**：`P39-1.jpg` 放到 `P39` 页第 1 个槽位。
不要在代码里写死图名。

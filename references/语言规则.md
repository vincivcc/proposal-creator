# 文案的语言规则（内部约束，不进方案）

约束我写的**每一句**文案。这些规则本身**绝不能作为一页出现在方案里**——
客户不需要知道我们的写作规范，规则的价值体现在结果（正文的语言）上，
声明出来等于在方案里教客户做事，还占篇幅。

## 五条规则

**1 · 不解释。**
「你睡着以后」比「夜间修护科技」高级——前者不需要说服，后者一直在辩解。

**2 · 不用感叹号。**
不用「必入」「绝了」「YYDS」。品牌说话的方式，决定别人怎么看它。

**3 · 形容词减半，动词和名词加倍。**
「质地轻盈、吸收迅速」是说明书；「它不黏，你翻身的时候想不起它」才是文案。

**4 · 数字只做证据，不做修辞。**
500+ 多肽是产品事实——写出来就够了，不用再加「卓效」。

**5 · 不承诺效果。**
「修复中」是状态，不是结果。

## 五组对照

给文案时给正反例对照，比讲方法论有效。

| 常见的写法 | 我们的说法 |
|---|---|
| ~~全新升级，焕活夜间修护力~~ | **你睡着以后，它才开始工作** |
| ~~熬夜党必入！第二天脸不垮~~ | **白天欠下的，夜里慢慢还** |
| ~~蕴含 500+ 修护高能肽，卓效修护~~ | **500 多种肽。它们的工作时间是夜里。** |
| ~~贵妇级奢华质地，一夜回春~~ | **好的质地，是不需要被想起的那种** |
| ~~医美后必备，安心修护~~ | **做完医美的那几天，别乱用东西。用它。** |

## 一个自检

写完一句，问自己：**这句话是在描述，还是在推销？**
描述留下，推销删掉。

## 可以外发

这份规则可以直接当 KOL / 达人 brief 的语气附件发给执行方。
